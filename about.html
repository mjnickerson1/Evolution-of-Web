About This Project

This website was created as part of the IT 3203 Web Development course at Kennesaw State University.

The purpose of this project is to research the evolution of the World Wide Web while applying HTML and CSS skills to create an educational website.

The website explores the history of the web, the transition from Web 1.0 to Web 2.0, and emerging Web 3.0 technologies.
